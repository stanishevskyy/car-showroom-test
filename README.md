# Car Showroom 🚗

Тестове завдання **"Car Showroom"** — це SPA-застосунок віртуального автосалону, який дозволяє переглядати список автомобілів, шукати та фільтрувати моделі, переглядати детальну інформацію про автомобіль і залишати власні відгуки.

## 🚀 Demo

Live preview:

https://stanishevskyy.github.io/car-showroom-test/

---

## 📌 Опис проєкту

Застосунок реалізований на **React** та працює з даними з публічного API **DummyJSON**.

Користувач може:

- переглядати список доступних автомобілів;
- шукати автомобілі за назвою;
- фільтрувати за брендом та ціною;
- сортувати автомобілі;
- переглядати детальну інформацію про конкретний автомобіль;
- переглядати існуючі відгуки;
- додавати власні відгуки з оцінкою;
- зберігати додані відгуки у `localStorage`.

## 📄 Сторінки

### Головна сторінка `/`

Містить:

- список автомобілів;
- пошук;
- фільтрацію:
  - бренд;
  - ціна;
  - сортування;
- адаптивну панель фільтрів для мобільних пристроїв.

---

### Сторінка автомобіля `/vehicles/:vehicleId`

Містить:

- галерею автомобіля;
- детальну інформацію;
- характеристики;
- список відгуків;
- форму додавання нового відгуку.

---

## 💬 Відгуки

Нові відгуки:

- проходять базову валідацію;
- зберігаються у `localStorage`;
- об'єднуються з відгуками, отриманими з API;
- відображаються після перезавантаження сторінки.

Поля форми:

- ім'я;
- email;
- оцінка;
- коментар.

---

## 🔗 API

Дані автомобілів отримуються з:

DummyJSON API:

```
https://dummyjson.com/products
```

Використовується категорія:

```
vehicle
```

## ⚙️ Запуск проєкту локально

Клонувати репозиторій:

```bash
git clone https://github.com/<your-username>/car-showroom-test.git
```

Перейти у папку:

```bash
cd car-showroom-test
```

Встановити залежності:

```bash
npm install
```

Запустити dev сервер:

```bash
npm run dev
```
